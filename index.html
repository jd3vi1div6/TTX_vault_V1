A self-contained web app for facilitating, tracking, and analyzing cybersecurity tabletop exercises. Run scenarios with your team, capture observations and risk assessments under pressure, and visualize organizational exposure through the integrated CREM console.

► CAPABILITIES
  • Two pre-built scenarios (breach, ransomware) with 6–7 phases each
  • Participant and facilitator modes with hidden tips
  • MITRE ATT&CK technique mapping per inject
  • Live risk assessment capture (impact, likelihood, data, regulatory)
  • Observation logging — gaps, actions, strengths, notes
  • Plain-text exercise report export
  • Mock CREM console with attack-path visualization
  • 100% client-side · no server · works offline
► TECH STACK
  • Vanilla HTML / CSS / JavaScript — no frameworks
  • Inline SVG charts (no external chart libs)
  • Hosted on GitHub Pages
  • Pip-Boy + Vault-Tec aesthetic (Share Tech Mono / VT323)
  • Self-contained — drop into any static host
